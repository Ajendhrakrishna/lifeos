# LifeStack

A personal management app that connects tasks and money. See [PLAN.md](PLAN.md) for the full plan.

## Setup

1. Install Node.js 22 LTS or newer (`node -v`).
2. Install dependencies:
   ```
   npm install
   ```
3. Copy `.env.example` to `.env` and fill in your Supabase values. `.env` is ignored by Git, so never commit it.

## Run

```
npm run dev     # restarts automatically when you save a file
npm start       # normal start
npm test        # run tests
```

Then open http://localhost:3000
